# Compatible convenience-content integration

New Horizons includes compatible convenience features directly in the curated
edition; players should not manage optional mods. This does not authorize unrelated
gameplay changes, multiplayer activation or redistribution of every upstream asset.

## Component admission

For each Extras component identify pinned source, runtime consumer, current
equivalent, dependencies/conflicts, enabled/conditional/excluded state, provenance,
modifications and acceptance route. Preserve identifiers/dependency semantics where
practical. Avoid duplicate controls from overlapping widget/overlay definitions.
A useful equivalent may be independently authored where rights are unresolved.

QS/QL controls preserve F8/F9 and adapt to compact/expanded/portrait layout anchors.
A copied coordinate is not an adaptive layout. Creature ability/status coverage
must follow actual bonuses/subtypes and tooltips: Pikeman/Halberdier Charge Immunity
must not be mislabelled First Strike or changed mechanically to repair an icon.
One new icon does not complete the whole ability catalogue.

Templates are authoring references with native dimensions, margins, frame/state
ordering and provenance, not gameplay dependencies. Do not execute bundled tools
or redistribute the whole template pack merely to make authoring inputs available.
Selected runtime composites follow the NHART packaging policy; unchanged original
resources remain external.

## Rights and evidence

Do not infer graphic licenses from VCMI's GPL or missing repository metadata.
Inspect selected files' notices individually; declared template-pack licenses do
not independently clear underlying purchaser pixels. Preserve legitimate attribution
without publishing unnecessary personal metadata. Do not initiate permission
outreach or account changes without authority.

Validate exact bindings, subtype/fallback behavior and duplicate-control exclusion,
then normal QS/QL round trip and representative creature panels on an immutable
candidate. Check layouts at native resolution. Windows package checks are not
native Windows interaction. See [content acceptance](NH_CONTENT_ACCEPTANCE.md)
and [delivery](NH_DELIVERY_PIPELINE.md).
