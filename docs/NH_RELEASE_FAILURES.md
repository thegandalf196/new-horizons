# Release regression lessons

The maintained safeguards are in [NH_REGRESSION_GUARDS.md](NH_REGRESSION_GUARDS.md), the [performance/restart contract](NH_PERFORMANCE_EXPERIMENT.md) and [Windows acceptance](NH_WINDOWS_ACCEPTANCE.md). Per-attempt compiler logs, candidate identities, process receipts and discarded fixtures belong in private storage, not an append-only public diary.

For a recurring defect, retain the confirmed cause, smallest reproducer, prior repair, protected invariant, focused test, target-platform verification and remaining scope. A failed fixture is not a production defect, but never waive gameplay, serialization, privacy or ownership invariants to make it pass.

Important retained lessons: direct owning headers for serializer graphs; cross-platform designated-initializer/type rules; legal action/perk fixtures; BonusList lifetime and snapshot identity; captured-policy/version admission before mutation/broadcast; complete dependency source/notice and PE closure; binary privacy beyond debug stripping; and separate rendered acceptance from source/container/compile evidence.
