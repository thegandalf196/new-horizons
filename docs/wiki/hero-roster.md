# Standard hero starting roster

[Wiki home](README.md) · [Heroes and specialties](heroes.md) · [Hero roster](hero-roster.md) · [Classes](classes.md) · [Progression](progression.md) · [Skills](skills/README.md)

These are the ordinary new-game development starts for **all 144 heroes with authored New Horizons starting profiles**. Each row lists the hero's current class, both starting Skills with their ranks, and the starting perk. The faction Skill is included in the Skill column. Map and campaign availability rules still apply.

Scenario-authored starts and older saved campaigns can differ. This roster does not list starting armies, spellbooks/equipment, biographies or every specialty; see [Heroes and specialties](heroes.md) for the currently documented individual effects. Campaign-only and special heroes are outside this standard roster.
