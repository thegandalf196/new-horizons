# Classes and attributes

[Wiki home](README.md) · [Heroes and specialties](heroes.md) · [Hero roster](hero-roster.md) · [Classes](classes.md) · [Progression](progression.md) · [Skills](skills/README.md)

All 18 standard classes use fixed class-base growth. **A / D / P / K** means **Attack / Defense / Spell Power / Knowledge**, in that order.

The starting values below are the class base at level 1, before individual bonuses, equipment or scenario overrides. Each subsequent level adds the listed growth vector: `base at level L = starting values + (L - 1) × growth`, subject to the game's attribute limits. The class contribution totals 100 points at level 1 and 20 additional points per level. Learned Skills can supply separate bonus attribute rolls; see [Skill-based growth](progression.md#skill-based-attribute-growth).

## Class names and hero swaps

Academy's former Alchemist class is named **Battle Mage**. Stronghold's former Battle Mage class is named **Shaman**. Inferno's former Demoniac and Heretic classes are named **Tyrant** and **Cultist**.

**Halon is a Battle Mage and Thane is a Wizard.** The [hero roster](hero-roster.md#academy) places them with their current classes, rather than leaving them in their old class groups.

Might classes can develop Command, while Magic classes can develop Wisdom. Neither that eligibility nor a class name adds an unlisted Skill to a hero's [authored ordinary start](hero-roster.md). Hero Attack and Defense do not automatically add to creature Attack and Defense; see [Hero attributes](progression.md#hero-attributes).
