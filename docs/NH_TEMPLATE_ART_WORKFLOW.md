## Rights and provenance

The reference module declares CC BY-SA4.0 and author Various; its notes also identify Complete/HotA/reconstructed imagery. API license-null is not proof there is no declaration, nor does a blanket declaration independently clear every underlying pixel.

For any selected composite, record exact per-file origin, terms, attribution, modifications and inherited game-content dependency. Do not relabel CC BY-SA/proprietary pixels CC0 or assume code licensing covers art. Unclear imports stay excluded until resolved; purchaser reference is not redistribution permission. Preserve legitimate notices and selected original-based package direction.

## Production and regression contract

Select pinned native templates privately; generate only original separated foregrounds with actual alpha. Use explicit slot scale/offset/safe-border masks and premultiplied-alpha filtering; preserve template pixels outside the declared mask. Do not rough-threshold opaque art or recolor leather per Skill.

Review native32/44/82×93 and larger views for silhouette, material/contrast, halos, clipping and rank/state meaning. Preserve masters, prompts, alternatives and exact inputs privately. Approval, technical output validation, selection and in-game rendering are separate.

Tests must reject mismatched sizes/missing alpha, preserve inputs/protected pixels, verify dimensions/margins/partial edges and record provenance. No plugin, manual user masking, external-service account or automatic live importer is required. Selected distribution remains [NHART](NHART_DELIVERY.md), never loose public authoring exports.
