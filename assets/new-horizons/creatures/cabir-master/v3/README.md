# Barehanded Cabir Master — provisional standing master

Original built-in image generation using HoMM3 Art. `standing.prompt.txt` records
the exact brief; the base v3 master is the identity reference and the earlier
upgraded standing draft supplies shoulder-armor treatment only. Both hands are
empty: this supersedes the golden-pot design. Original project artwork is
dedicated under CC0-1.0. No extracted purchaser pixels are included.

The RGBA master is 1323×1189, SHA-256
`c1c88872bf0cc8e969f9d883b289aff86071db31241d35a16255b74532fbca15`.
Native exports, motion, ranged and repair poses, remaining animation groups,
portraits and runtime bindings are not complete. This is not playable delivery.

`walk-v1/candidate-01.png` is a provisional upgraded 2×2 walking atlas, generated
from this master and the base v3 walk-v2 source. Its exact edit prompt is retained
beside it. Native alignment, gait and alpha cleanup are not yet verified.
