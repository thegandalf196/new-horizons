# heavenly-gale — transparent spell symbol

This historical symbol-only revision was created with the built-in image
generator from the original project painting identified by
`../heavenly-gale-v1/master.png`. Artwork: GPL-2.0-or-later. Status:
Provisional; native export inspection is not rendered acceptance or Final
approval. Complete authoring masters and earlier exports remain external.

## Native symbol contract

The identifying subject is a shield, one outward-pointing arrow and a compact
curving wind trail. Keep the complete emblem unclipped within a clear inset.
The symbol uses genuine RGBA transparency around the subject and through its
holes, with no painted rectangular backdrop, parchment, frame or interface.
The guild parchment belongs to the separate game UI surface.

The historical export copied the RGBA master and reduced to 44×44, 32×32 and
30×30 pixels with LANCZOS, preserving alpha. Dimensions, source/export hashes
and comparison geometry remain in `heavenly-gale-symbol-manifest.json`.
The retained standalone helper is `skills/homm3-art/scripts/export_art.py`
within the complete external tool archive; it is not shipped in this checkout.
Replaying an export requires a reviewed absolute path to that script, Pillow
and complete external master inputs, not plugin installation or activation.
Public records cannot recreate a missing master. Ordinary builds consume
selected NHART resources without that authoring archive.
