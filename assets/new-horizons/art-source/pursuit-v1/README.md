# Pursuit provisional art v1

This original icon was generated with the OpenAI built-in image generator
through the `homm3-art` workflow on 2026-09-27 without input images. The exact
prompt and generation record are retained beside the icon exports. The asset
is provisional and has not received final visual approval.

The export directory retains the generated 1254×1254 RGBA master, deterministic
44×44 and 32×32 LANCZOS reductions, a labeled comparison sheet, and the
exporter manifest. `export-runtime.py` derives the four 44×44 VCMI button
states by brightness/color adjustment only. `generation.json` records the
generation provenance and normalized source identifier; `runtime-manifest.json`
records the asset-level link to `new-horizons:offense.pursuit` and runtime file
hashes. The client perk icon resolver is intentionally not changed while this
perk remains planned.

The forward-driving leather boot and steel spur passing a shattered helmet
suggest movement continuing beyond a defeated enemy. Source art and deterministic
exports are contributed under CC0-1.0.
