# Active perk provisional art v4

Four distinct provisional icons close the active-perk presentation gap:

- Entrench: shovel, earthwork, timber stakes, and sheltered shield.
- Executioner: execution axe over a broken crown.
- Armor Piercer: bodkin arrow driven through plate armor.
- Breakthrough: warhammer breaching a stone wall.

The masters were generated independently with the `homm3-art` workflow as
miniature modeled fantasy still lifes. The repository export helper produced
44x44 and 32x32 LANCZOS reductions and comparison sheets. `export-runtime.py`
derives the four VCMI button states using brightness/color changes only.

These assets are provisional and have not been designated definitive art by
the user.
