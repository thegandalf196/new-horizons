# Spell Penetration provisional art v1

Purpose-made original artwork for `new-horizons:spellcraft.spellPenetration`,
generated with the built-in image generator through the `homm3-art` workflow
on 2026-09-28. No user image or external style-reference pixels were used.
The exact prompt and host output identifier are retained in
`prompt-spell-penetration.txt` and `generation.json`.

The selected 1254×1254 master, deterministic 44×44 and 32×32 LANCZOS
reductions, labeled comparison, and reduction manifest are under
`exports/spell-penetration/`. `export-runtime.py` derives the four VCMI
44×44 button states using brightness and color adjustments only. Runtime
copies and the descriptor are retained under `runtime/` and installed under
`Mods/new-horizons/Images/`; their hashes are recorded in
`runtime-manifest.json`. The client binding uses `NH_perk_spell_penetration`.

At native 44×44 and 32×32, the diagonal lance, violet ward, and central breach
remain distinguishable. Fine engraving and the smallest fracture details
merge at icon size as intended. Status is provisional: no final art approval
or in-game visual acceptance is recorded.
