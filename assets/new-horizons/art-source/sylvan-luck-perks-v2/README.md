# Sylvan Luck activation perk placeholders v2

Original provisional artwork generated with the host image generator on
2026-09-20 for New Horizons. The atlas contains, left to right, Forest's Favor,
Lucky Recovery, Shared Fortune, and Cascading Fortune. No purchaser or
third-party artwork is embedded. Runtime crops and button states are produced
mechanically by `export.py`; source and outputs are contributed under CC0-1.0.

These icons remain provisional pending later art polish, but each active perk
has a distinct readable subject and complete runtime states.
