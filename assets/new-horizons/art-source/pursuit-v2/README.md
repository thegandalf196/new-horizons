# Pursuit provisional art v2

This selected revision originated with the OpenAI built-in image generator
on 2026-09-27 as a framing correction of an earlier generated image. It is
provisional and has not received final visual approval. Exact prompts, raw
generation metadata, source masters and review materials are maintained in
private authoring storage.

`generation.json` retains the selected source hash, origin, license, resource
binding and technical export contract. `runtime-manifest.json` records the
four 44×44 button states and animation descriptor with their selected hashes.
`export-runtime.py` derives those states in an explicit external authoring
mirror using brightness/color adjustments after LANCZOS reduction.

The selected runtime payloads are distributed in `NewHorizons.nhart`; the
canonical selected-resource identities, hashes, origin and review state are in
`assets/new-horizons/runtime-art-manifest.json`. A normal build does not require
private authoring inputs or regenerate the pack.

The complete forward-driving leather boot and steel spur passing a shattered
helmet suggest movement continuing after a melee kill. Source art and
deterministic exports are contributed under CC0-1.0.
