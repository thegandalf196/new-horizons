# Pursuit provisional art v2

This selected revision was generated with the OpenAI built-in image generator
through the `homm3-art` workflow on 2026-09-27. It is a framing correction of
the retained v1 generated image; the exact edit prompt is in
[`prompt-pursuit-v2.txt`](prompt-pursuit-v2.txt). Version 1 remains preserved
under `../pursuit-v1/`. This asset is provisional and has not received final
visual approval.

The export directory retains the 1254×1254 RGBA master, deterministic 44×44
and 32×32 LANCZOS reductions, a labeled comparison sheet, and the exporter
manifest. `export-runtime.py` derives four 44×44 VCMI button states using
brightness/color-only adjustments. `generation.json` records the source image,
prompt, and output provenance. The asset-level link maps
`new-horizons:offense.pursuit` to `NH_perk_pursuit_v2`; the client perk icon
resolver uses this provisional asset while the perk is active.

The complete forward-driving leather boot and steel spur passing a shattered
helmet suggest movement continuing after a melee kill. Source art and
deterministic exports are contributed under CC0-1.0.
