# Encirclement provisional art v1

This original perk icon was generated with the OpenAI built-in image generator
through the `homm3-art` workflow on 2026-09-27, without input images. The exact
prompt is preserved in [`prompt-encirclement.txt`](prompt-encirclement.txt). It
is provisional and has not been designated definitive artwork.

The export folder retains the original 1254x1254 RGB master, deterministic
44x44 and 32x32 LANCZOS reductions, a labeled comparison sheet, and the helper
manifest. `export-runtime.py` derives the four 44x44 VCMI button states using
brightness and color adjustments only. `generation.json` records provenance,
the master SHA-256, dimensions, and source identifier; runtime hashes are
recorded in `runtime-manifest.json`.

The central battered shield and three clearly distinct converging weapons depict
the stronger coordinated damage gained from additional Flank attack sides. The
generated source art and deterministic export code are contributed under
CC0-1.0, consistent with the project's other original perk-art sets.
