# Creature stat glyphs — provisional

Original built-in image generation using the HoMM3 Art skill. These retained
masters and 20px runtime exports reuse the previously generated creature rank v2
and creature Leadership v1 drafts; this integration did not generate new artwork.
No original-game pixels or third-party template pixels are included.

The user's simple yellow glyph direction overrides the skill's default painted
still-life treatment. Rank is a stair-step line, not a rung ladder. Leadership is
a crown. The staircase used the user's screenshot solely as a shape reference,
not as an edit target; the crown used no image reference. The reference itself is
not distributed. Exact generation prompts follow below.

Exports were produced with the HoMM3 Art skill's `export_art.py`, RGBA LANCZOS
reduction from the square masters, without masking, recoloring or sharpening.
The integration copies those export bytes unchanged. The manifest pins both
masters and runtime files. Both masters are 1254×1254 RGBA with actual alpha;
repository masters omit the generated caBX metadata carrier without changing
IHDR/IDAT/IEND bytes or decoded pixels. The original generated bytes remain in
the private draft directories, with their hashes recorded in the manifest.
runtime icons are 20×20 RGBA. Root inspected the master comparison, native 20px
icons and enlarged 32/44px comparison. Art and integration remain Provisional:
no final user approval or in-game rendered acceptance is claimed.

## Rank prompt

Create an ORIGINAL simple monochrome yellow UI glyph for creature rank in a Heroes III inspired game. Subject is a stair-step ascending line, NOT a ladder with rungs: one continuous thick uniform stroke starts at lower left, goes horizontally right, vertically up, horizontally right, vertically up, horizontally right, vertically up, horizontally right, vertically up, and finishes horizontally toward upper right. Four equal rises and five equal horizontal treads, mildly rounded corners and round endpoints. Flat single solid muted golden yellow #D8C66A throughout, absolutely no shading, bevel, 3D depth, glow, outline or gradients. Transparent background, no checkerboard painted into image. Square canvas, symbol centered occupying 80 percent with consistent safe inset. No text, watermark, border, rails, rungs, base triangle or other objects. This is a fresh generic staircase pictogram, not stock art. User reference conveys only this simple staircase silhouette. The user's explicit flat monochrome direction takes precedence over the art skill's painted still-life defaults.

## Leadership prompt

Create a single square game UI stat glyph, original Heroes III inspired. User explicitly requests SIMPLE MONOCHROME YELLOW, overriding detailed still-life treatment: restrained antique yellow-gold silhouette with only subtle same-hue light/shade, broad bold shapes readable at 20 pixels. Centered, occupies 78 percent, generous consistent inset. Transparent background outside symbol. No tile/background, no frame, no text, no numbers, no gradients into other colors, no glow, no elaborate decoration, no realistic scene. Subject: a simple front-facing royal crown, three broad points, center point tallest, plain solid curved band at bottom. No jewels, no crosses, no filigree. Strong uncluttered silhouette.
