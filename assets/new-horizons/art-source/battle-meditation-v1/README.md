# Battle Meditation provisional art v1

This original perk icon was generated with the OpenAI built-in image generator
on 2026-09-23, without input images or style references. It is provisional and
has not been designated definitive artwork. The exact prompt is preserved in
[`prompt-battle-meditation.txt`](prompt-battle-meditation.txt).

The export folder preserves the original 1254×1254 master, deterministic
44×44 and 32×32 LANCZOS reductions, and a labeled comparison sheet. The runtime
export script derives the four 44×44 VCMI button states from the 44×44 icon with
brightness and color adjustments only. Source artwork, exact prompt, and
deterministic export code are dedicated to the public domain under CC0-1.0.

`generation.json` records the effect identity, generator provenance, and the
generated-image-cache path relative to `$CODEX_HOME`, plus the retained
master's relative path, dimensions, and SHA-256. Per-export and runtime hashes
are recorded in their manifests.
