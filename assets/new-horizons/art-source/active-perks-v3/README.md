# Shock Assault provisional art

Original provisional perk painting generated with the built-in image generator
on 2026-09-21. No external image was used as a pixel or style reference. The
high-resolution master is reduced mechanically for runtime use; it is not final
user-approved artwork.

Run `export.py` with an absolute Pillow-enabled interpreter and the absolute
`homm3-art/scripts/export_art.py` path to produce the source previews and four
44-pixel runtime states.
