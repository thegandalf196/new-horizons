# Academy map materials — revision v2

Historical status: provisional, installed in source; user in-game aesthetic
acceptance and playable delivery are separate and are not claimed here.

Village, Fort and Capitol are authored 1254×1254 RGBA masters. Material edits
preserve their respective architecture, silhouettes, entrances, footing and
pennants. Registration uses the exact prior master and destination boxes,
not incidental low-alpha shadow bounds. Ownership flags and shadows retain
their independent external-resource composition; gameplay, entrance and
blocking changes are outside this artwork revision.

The map-v2 exporter reproduces registered 192×192 outputs from complete
preserved authored inputs. The importer pins the revision manifest's source
registration, original/revised master identities, prompt hashes, geometry and
export hashes, and rejects unknown replacements before installation. Private
masters and prompts are authoring inputs, not artwork to reconstruct from
runtime exports. Earlier source and provenance remain preserved unchanged.
No new licence is assigned to supplied artwork, and technical reproducibility
does not establish user visual acceptance or rendered/playable delivery.
