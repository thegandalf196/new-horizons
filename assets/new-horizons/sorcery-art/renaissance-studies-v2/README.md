The user rejected both Meridian/Aperture as too modern / Heroes: Olden Era-like.
Any worker preference for A is superseded. This revision does not texture or
recolour those forms: no gem, orb, beveled shield or circular medallion is used.

Working hypotheses, not a user-approved style definition:
1. Magician's Study: open worn book, wax candle, dividers and receding shelves;
   warm localized light and cool folded cloth, an asymmetric still life.
2. Conjurer: expressive warm hand lifting a folded leaf against theatre curtains;
   palm/finger planes and patterned cuff, not a jewelry emblem.
3. Celestial Manuscript: painted vaulted cosmology with sea/stair/stars on a worn
   leaf, beside a quill and ink; not an empty wireframe instrument diagram.

Each is only a header, two bookmark states and native32/82x93 skill samples. The
samples have no assigned rank yet: distinct rank progression and all20 final
assets are work AFTER explicit user choice. No full family is implied by samples.
Headers keep top28 transparent, all assets require clear outer pixels. Sheets
include compact68x51 tabs as well as native80x60; labels are outside art canvases.

`paint.py` is newly authored CC0 Python/Pillow code with manually placed polygons,
material-value planes and directional brush lines; no noise, gradient gloss,
image-generation service, downloaded image/font/texture or purchaser pixels.
Output PNGs are painted at target resolution. Native32 uses a separately composed
crop/arrangement, not reduced large artwork. Matching standalone SVG paths/groups
are editable equivalents of that geometry, with no embedded raster/external data.
Python is the authoritative native-pixel exporter; SVG edge rasterization may
vary across renderers and is not asserted byte-identical to Pillow.
