# Development-only runtime exports

These retained exports are development/reference inputs, not a player resource
mount. Some are superseded by the selected Cabir, turbaned Magi, Wisp and Guild
handoffs. Their presence does not imply current selection or visual approval.
Authoring masters and review materials remain in their original locations.

The selected presentation is pinned by `../runtime-art-manifest.json` and shipped
only in `Mods/new-horizons/NewHorizons.nhart`. That manifest's source paths are
relative to an explicitly prepared input staging root, not an instruction to
load loose images from this directory. Ordinary builds verify the committed
container without regenerating it from this incomplete development collection.

Preserve existing provenance and license records. Moving these files does not
remove their earlier copies from Git history or make original-derived artwork
independently authored.
