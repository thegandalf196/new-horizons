# Local runtime authoring inputs

Loose exports, authoring masters, alternatives and review materials are maintained
in verified local backups or explicitly configured external staging roots. They
are not committed by default and must not be recreated in this tracked directory.
Some historical exports were superseded by the selected Cabir, turbaned Magi,
Wisp and Guild handoffs. Local retention does not imply selection or approval.

The selected presentation is pinned by `../runtime-art-manifest.json` and shipped
only in `Mods/new-horizons/NewHorizons.nhart`. That manifest's source paths are
relative to an explicitly prepared input staging root, not an instruction to
load loose images from this directory. Ordinary builds verify the committed
container without access to local authoring inputs. The public repository retains
the package, tools, manifests and records, not a parallel loose-art collection.

Preserve existing provenance and license records. Moving these files does not
remove their earlier copies from Git history or make original-derived artwork
independently authored.
